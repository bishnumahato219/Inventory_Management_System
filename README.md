* 🔎 Search & Filter System

## 🚀 Getting Started (Local Setup)

### 1. Clone Repository

```
git clone https://github.com/bishnumahato219/Inventory_Management_System.git
```

### 2. Install Dependencies

```
cd mahato-motors-frontend
npm install

cd ../mahato-motors-backend
npm install
```

### 3. Run Project

```
# Backend
npm run dev

# Frontend
npm run dev
```
